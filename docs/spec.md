## 1. 产品概述

银耳专注是一款只在 macOS 上运行的菜单栏专注计时应用，用来替代银耳正在订阅的 Flow Pro（美区年付 Yearly Plan，17.99 美元/年）。它把工作拆成专注与休息，在专注进行中屏蔽指定应用和网站，在本机保存历史并统计，也可把已完成的专注写入系统日历。

约束（已批准）：

- 使用者：银耳，只有一台 Mac（MacBook Air M4，macOS 27）
- 只在本地运行，不自建服务器，不做账号系统，不引入 Firebase 或其他云服务
- 不做多设备同步（含 iCloud 统计同步和 Timer Sync）
- 技术栈：Swift 与 SwiftUI
- 形态：菜单栏应用，不显示 Dock 图标
- 界面语言：简体中文
- 第一版只做 Mac，不做 iPhone、iPad、Apple Watch、Apple Vision
- 不需要支持 Firefox
- 不接任何付费服务或应用内购买

默认周期与 Flow 公开文档一致：专注 25 分钟，短休息 5 分钟，每完成 4 次专注后进入 30 分钟长休息。计时器有三种状态：待开始、进行中、已暂停。

## 3. 用户流程

### 3.1 日常专注

1. 登录后若开启了「登录时启动」，应用只出现在菜单栏，不占据 Dock。
2. 点击菜单栏图标，打开主弹窗。弹窗显示当前阶段（专注、短休息或长休息）、剩余时间、周期进度，以及开始或暂停按钮。
3. 可选：给这场专注命名、选择一个标签（例如「学习」）。
4. 按开始，倒计时开始。若设置了「计时开始后隐藏窗口」，主弹窗关闭，菜单栏图标继续显示剩余时间。
5. 可随时暂停，剩余时间保留；再开始则从停下的地方继续。
6. 计时到零：发出通知。若未打开自动开始，下一阶段保持「待开始」，等用户再按开始。若打开了「专注结束后自动开始休息」或「休息结束后自动开始专注」，则自动进入下一阶段。
7. 休息期间可跳过休息，直接进入下一场待开始或直接开始的专注（与设置一致，默认跳过后进入待开始，需再按开始，除非打开了自动开始专注）。
8. 可重置周期，回到周期开头的一场待开始专注，不自动开计时。
9. 一场专注完成后写入本机历史；若已开启日历同步，同时写入所选日历。

### 3.2 专注时屏蔽

1. 用户在设置里维护应用名单与网页名单，并选择「阻止」或「允许」，以及要监视的浏览器。
2. 仅当专注处于「进行中」时启用屏蔽。
3. 若用户点开名单中应被拦截的应用，该应用会在被激活的瞬间被隐藏（退到后台），用户回到原先的工作界面。不强制退出该应用的进程。
4. 若已选中的浏览器打开了应被拦截的网址，该标签的整页被替换为原创拦截页。休息或暂停后，不再替换新打开的页面；已经显示拦截页的标签不会被自动改回去，用户可自行导航到其他地址。

### 3.3 查看统计与迁移

1. 从主弹窗进入统计，查看图表和会话列表。
2. 可导入 Flow 导出的 CSV（见第 8 节），以便带上既有历史。
3. 可按同样列把本应用的已完成会话导出为 CSV。

## 4. 界面

总体：简约、系统原生、支持浅色与深色并默认跟随系统。不使用 Flow 的图标、绿色波形标志或「封锁」等原样文案。窗口圆角与菜单栏弹窗尺寸应对齐常见菜单栏应用的使用习惯，具体视觉由实现时原创设计，下面只约束信息和结构。

### 4.1 菜单栏与主弹窗

- 无 Dock 图标，无正式的应用窗口出现在 Cmd+Tab 中作为常规文档窗口亦可，但设置和统计可以是独立面板。第一版允许主界面只存在于菜单栏弹窗，统计与设置用独立窗口或同一弹窗内的子页。
- 菜单栏图标在「进行中」显示剩余时间（至少精确到分钟，推荐分与秒都可见，或分钟加进度）；「待开始」与「已暂停」要能区分；休息阶段用颜色或形状与专注区分（第一版一种默认样式即可）。
- 主弹窗内容：会话标题（可点击编辑，空则显示占位如「专注」）、当前阶段、剩余时间、周期进度（例如第 2 次，共 4 次）、标签选择、开始或暂停、跳过休息（仅休息时可用）、重置周期（已在周期开头时可隐藏或禁用）。
- 入口：设置、统计。
- 点击菜单栏图标再次点击可关闭弹窗。右键菜单第一版至少提供：开始或暂停、打开主弹窗、打开设置、退出应用。

### 4.2 设置

至少包含：

- 时长：专注预设 15、20、25、30、45、50、60、90 分钟，默认 25；短休息预设 5、10，默认 5；长休息预设 15、20、30，默认 30。自定义 1 至 90 分钟作为默认项（待确认）。周期长度 1 至 10，默认 4。
- 自动开始：两个独立开关，默认都关闭。
- 通知：专注结束、休息结束可开关；系统会在首次需要时请求通知权限。
- 启动：登录时启动（推荐默认打开，因为屏蔽依赖应用常驻）、启动时显示主弹窗、启动时重置周期、启动时开始专注。
- 窗口：计时开始后隐藏主弹窗；窗口是否置顶。全屏休息第一版不做。
- 外观：跟随系统、浅色、深色。
- 标签管理：增删改、排序、颜色。预置「工作」「个人」「学习」，可改可删。一场会话最多一个标签，也可不选。第一版不做「标签带预设套用时长」。
- 屏蔽：进入「应用与网页屏蔽」子页，见 4.3。
- 日历：开关、选择一个日历。未授权时先走系统授权。
- 数据：导入 CSV、导出 CSV、重置全部统计（需二次确认，不可撤销）。
- 全局快捷键：设置入口保留，默认关闭（待确认）。
- 关于：应用名、版本、开源或源码归属说明（若以后公开仓库再补地址）。

### 4.3 屏蔽名单（对照银耳截图的结构，原创视觉）

结构必须功能等价，布局可再设计，不得照搬 Flow 的像素与图标。

- 顶部：返回，以及「应用」「网页」两个标签。
- 网页标签：
  - 输入框，占位文案用原创表述，功能是输入网站名称或规则后加入名单（例如「输入要拦截的网站」）。
  - 名单列表，例如 `x.com`。
  - 底部：添加、删除（删除对当前选中项生效；未选中时应不可用或明确提示）。
  - 「阻止 / 允许」模式切换：阻止是黑名单，名单内的网站在专注进行中被拦截；允许是只允许名单，名单外的网站被拦截。两种模式共用一份名单，切换后立即按新模式理解这份名单。
  - 浏览器选择：可多选。第一版列出 Safari、Google Chrome、Arc，以及一项「待确认的第三个浏览器（Cra）」占位（未确认前不接入真实进程）。选择器收起时可显示类似「Arc + 2」的摘要（已选数量大于 1 时，用第一个名称加其余数量）。
  - 可用一个简短说明或帮助按钮，解释规则：普通条目按「包含匹配」（不必写 `http` 或 `www`，例如 `x.com` 会匹配含该片段的网址）；若要以精确网址匹配且不含相近子域，条目以 `*` 开头。
- 应用标签：
  - 可从已安装应用中添加（系统应用选择器或本机应用列表）。
  - 名单上的应用在专注进行中若被激活，立即隐藏。
  - 第一版应用侧只做「阻止名单」，不做「只允许这些应用」。与银耳在网页侧需要的阻止/允许切换不同，避免第一版把系统应用误伤成除白名单外全部隐藏。
- 承诺模式相关的「运行中禁止改名单」第一版不做。

### 4.4 统计

- 图表：次数或时长，日、周、月、年。查看非「今天」时提供回到今天的入口。
- 会话列表：时间、标题、标签、时长。可打开详情、补记一场已完成会话、删除、显示或隐藏未完成会话、按标签筛选。
- 导出与导入入口可同时出现在统计和设置中，不必重复两套逻辑。

### 4.5 原创拦截页

银耳实测：Flow 会把整页换成深绿色背景，中间是 Flow 图标加红色禁止标记，大标题「封锁」，说明为「该网站在您的黑名单中。Flow 为您屏蔽了它，因此您可以专注于您的任务。」

新应用必须功能等价，但视觉和文案必须原创，例如：

- 整页替换当前标签，而不是只弹系统通知或让页面加载失败
- 使用新应用自己的图标或几何图形，不加 Flow 的波形标志
- 标题与说明不得出现「Flow」字样，也避免照抄「封锁」二字。可用例如「已暂停访问」作标题，说明写明这是用户自己设定的名单在生效，请回到正在进行的任务。允许模式与阻止模式下的说明要区分（「不在允许名单中」与「在拦截名单中」）
- 深色背景可以使用独立配色，不要复制该截图的绿色作为品牌色
- 拦截页是本地内容，不访问网络、不做远程统计，也不把页面访问送到云端

## 5. 数据模型与本地存储

全部数据只存在本机（建议 SwiftData 或同等本机数据库，路径在应用的 Application Support 下）。不使用 iCloud 容器，不开启 CloudKit。

### 5.1 会话（Session）

| 字段 | 说明 |
| --- | --- |
| id | UUID 字符串。导入时保留 CSV 中的 ID；本机新建则生成新的 UUID。 |
| type | 已证实专注会话导出为 `Flow`。休息行的 Type 取值未出现在样例中。本机存储需区分专注、短休息、长休息；导出专注会话时 Type 写 `Flow`。若导入遇到未知 Type，原样保留以便往返，不丢弃该行。 |
| title | 可选。样例中为空字符串。 |
| tag | 可选。最多一个。样例中出现「学习」，也有空标签。 |
| durationNet | 净专注或休息时长，对应 CSV 的 Duration。样例中一场为 00:05:49，同时段墙钟为 00:05:50，说明净时长不含（或部分扣除）中断或暂停。 |
| durationGross | 含中断的时长，对应 Duration With Interruptions。在样例中与「完成时间减开始时间」一致（23:46:24 至 23:52:14 为 5 分 50 秒）。 |
| startedAt | 开始时间，本地时区的墙钟时间。 |
| completedAt | 完成时间，可选（未完成会话可为空）。 |
| status | 进行中、已暂停、已完成、已中断或未完成（具体枚举由实现选定，但要能支撑列表里「显示未完成」）。 |
| cycleLengthSnapshot | 可选，记录完成时的周期设置，便于以后统计。第一版建议保存，不在界面强调。 |

时长计算规则（验收要覆盖）：

- 进行中暂停时，暂停区间计入 durationGross（若完成时间按墙钟计算），不计入 durationNet。
- 导出 Duration 与 Duration With Interruptions 均使用 `HH:MM:SS`（样例为两位小时，如 00:05:49）。
- 导出 Started、Completed 使用 `YYYY-MM-DD HH:MM:SS`，不带时区后缀，按本机时区（Asia/Shanghai）书写。

### 5.2 标签、设置、名单

- 标签：名称、颜色、排序。名称在本机唯一。
- 设置：时长、周期、自动开始、通知、启动、外观、日历开关与所选日历标识、浏览器选择、网页模式（阻止或允许）、全局快捷键（可空）。
- 网页规则：一条字符串规则（关键词或 `*` 前缀的精确规则）。
- 应用规则：应用的 Bundle ID 与显示名。

### 5.3 日历事件默认格式（待确认）

在银耳出示真实日历事件之前，采用如下默认，并在界面不提供复杂模板编辑（避免第一版范围膨胀）：

- 事件开始：会话的 startedAt
- 事件结束：会话的 completedAt（因此日历上的时长对应墙钟跨度，与 Duration With Interruptions 一致）
- 标题：若 title 非空则用 title；否则若有标签则为「专注 · {标签}」；否则为「专注」
- 备注：两行以内，包含净时长与含中断时长，例如「净时长 00:05:49」「含中断 00:05:50」。有标题且同时有标签时，标签可写在备注里

只写入已完成的专注（Type 为 Flow 或本机的专注类型），第一版不把休息写入日历。

## 6. 技术要求

### 6.1 运行环境与工程

- 最低系统：macOS 26.0。验收在银耳的 MacBook Air M4、macOS 27 上进行。只保证 Apple Silicon，不做 Intel 验收。
- 语言与界面：Swift、SwiftUI，必要时用 AppKit 做菜单栏与隐藏其他应用。
- 菜单栏应用：设置 `LSUIElement` 或同等方式，不显示 Dock 图标。
- 签名：第一版用银耳的苹果开发者账号进行开发证书或 Developer ID 签名，在本机安装运行。第一版不上 App Store。创建仓库、加入或续费开发者计划、上架之前仍需单独征得同意。
- App Sandbox：第一版关闭。原因是本应用需要向 Safari、Google Chrome、Arc 发送 Apple Events，并调用系统接口把其他应用隐藏；沙盒会显著增加失败面。以后若要上架，再单独评估沙盒、公证与权限文案。
- Hardened Runtime：可以开启，但必须允许 Apple Events（自动化）例外，否则网站拦截无法工作。
- App Group：若第一版包含「今日统计」小组件，则必须配置 App Group，由主应用把当日汇总写入共享容器，小组件只读该容器。若银耳确认第一版不做小组件，则可以先不建 App Group。
- 不引入任何付费 API、分析 SDK、崩溃统计云、Firebase 或自建后端。拦截页与规则匹配全部在本机完成。

### 6.2 网站拦截方案（已选定）

选定方案：用系统自动化（Apple Events / Scripting Bridge，而不是让用户去装浏览器扩展）读取已选浏览器里各个标签的 URL；若当前处于专注进行中且该 URL 匹配拦截规则，就把该标签导航到应用捆绑的本地拦截页（`file://` 或应用资源中的本地 HTML，不启动网络服务）。

选择该方案的原因：

1. 银耳实测的效果是「当前标签整页换成拦截页」，这与改写标签 URL、在标签内打开本地页面一致。系统网络内容过滤器更容易变成加载失败或系统拦截提示，难以稳定呈现自定义整页，并且需要用户批准系统扩展，第一版负担过重。
2. 银耳常用 Arc 与 Chrome，二者与 Safari 都可通过公开的自动化接口读取和设置标签 URL。不需要支持 Firefox（Firefox 的自动化接口弱，正好排除）。
3. 不自建服务器。本地 HTML 文件即可，不必在本机开 HTTP 端口。

浏览器覆盖：

- 必须支持：Safari、Google Chrome、Arc
- 预留：银耳提到的第三个「Cra」，名称未确认，不得猜测。确认后若属于可自动化的 Chromium 系或 Safari 系浏览器，按同一方案接入
- 明确不做：Firefox，以及其他未确认的浏览器

所需系统权限：

- 「自动化」（隐私与安全性中的 Automation / Apple Events）。对每个要监视的浏览器分别请求，用户必须允许「银耳专注」控制 Safari、Google Chrome、Arc 等。拒绝某一项时，仅该项浏览器不拦截，并在屏蔽设置里给出明确提示，而不是静默失败。
- 通知权限：用于专注或休息结束，与拦截无直接关系。
- 日历权限：仅在用户打开日历同步时请求完整日历访问。
- 第一版不把「辅助功能」列为网站拦截的必要权限。若实现时发现仅靠 Apple Events 无法稳定读取 Arc 或某 Chromium 浏览器的标签，再把辅助功能作为备选并写进待确认，而不是默认强求。
- 应用隐藏使用 `NSWorkspace` 前台应用通知，再加上对该进程的隐藏，通常不必辅助功能。若个别应用无法被隐藏，记入已知局限，不得改成强制结束进程（除非以后银耳明确要求）。

匹配规则：

- 普通条目：对完整 URL 做不区分大小写的包含匹配。用户不必写 `http` 或 `www`。名单中的 `x.com` 应匹配 `https://x.com/...`、`https://www.x.com/...` 等含 `x.com` 的地址。
- 以 `*` 开头的条目：按 Flow 文档的公开规则，匹配这一精确 URL，不把相近子域算进去。实现时去掉前缀 `*` 再做精确比较（含或不含末尾斜线的处理要在测试中固定一种，并保持导出导入一致）。
- 允许模式：只有名单匹配到的网站可以保留，其余在已选浏览器中的 http、https 页面应被替换。需要排除本地拦截页自身的 URL、空白页、浏览器内部页（如 `chrome://`、`safari-resource://`、`about:`、`file://` 下本应用的拦截页），避免循环跳转或把浏览器设置页误伤。
- 在所有已选浏览器的所有窗口、所有标签上生效，不只是前台标签。
- 轮询间隔应足够短，使「打开被拦网站后看到拦截页」发生在约 1 秒内。允许极短的原页面闪现，这是该方案的已知局限，应在测试中记录实际延迟。

已知局限（必须在设置说明或帮助里用简短文字告诉银耳）：

- 依赖用户为每个浏览器授予自动化权限，权限被关则失效
- 可能出现短暂闪现被拦页面
- 浏览器或系统升级可能导致自动化词典变化，需要回归
- 无痕或特殊配置文件窗口可能无法读取
- 返回键可能回到被拦地址，应用应再次拦截
- 不能拦截未选中、未授权的浏览器，也不能拦截其他应用内嵌的网页视图
- 「Cra」确认前不会对该浏览器生效
- 不是系统级网络拦截，因此不能在浏览器外阻止同一域名

### 6.3 应用拦截方案

在专注进行中，监听前台应用激活。若其 Bundle ID 在应用阻止名单中，立即将其隐藏（退到后台），不要结束进程。休息、暂停、停止时不隐藏。对本应用自身、以及用户正在用来操作本应用的界面，不得把本应用藏掉导致无法暂停计时。

## 7. 数据迁移

目标：银耳可以把 Flow 导出的 CSV 一次导入，历史出现在统计中；以后也可以从本应用导出一份列完全相同的 CSV。

样例文件：`/workspace/flow/samples/flow-export-sample.csv`

特征（已用文件字节核对）：

- UTF-8，换行为 LF，文件末尾没有额外空行
- 表头恰好为：`Type,Title,Tag,Duration,Duration With Interruptions,Started,Completed,ID`
- 表头字段不使用引号；`Type`、`Title`、`Tag`、`ID` 在数据行使用双引号；时长与时间戳无引号
- 空标题、空标签写为 `""`
- 样例三行均为 Type `Flow`，标题均为空；两行标签为「学习」，一行标签为空
- 其中一行 Duration 与 Duration With Interruptions 相差 1 秒，导入后两字段都要保留，不得合成一个数

导入规则：

- 按 ID 去重：已存在相同 ID 则更新或跳过（第一版采用「相同 ID 则跳过，不覆盖本机可能已修改的记录」，并在导入结果里报告跳过条数）。不允许因重复导入出现重复会话。
- 标签名称若本机不存在，自动创建（颜色用默认色）。
- 无法解析的行要报告，不得让整次导入静默失败。
- 不要求银耳先卸载 Flow。新旧应用可以暂时并存。

导出规则：

- 列名、顺序、时间格式、时长格式与样例一致
- 专注会话 Type 为 `Flow`
- ID、标题、标签加引号；能往返导入自己导出的文件
- 第一版导出已完成的专注；是否导出休息行，因样例中没有休息 Type，第一版默认不导出休息，待确认

## 8. 验收测试

下列为可执行的验收项。自动化指可在工程里用单元测试或集成测试固定（不依赖银耳手动点浏览器）。手动指必须在银耳的 MacBook Air M4、macOS 27 上，对着真实的 Safari、Google Chrome、Arc 和真实日历完成，并保留截图或短录屏作为证据。

共计 48 项：自动化 20 项，手动 28 项。

### 8.1 自动化（20）

A01 默认周期：新的一轮从专注开始，完成 4 次专注后下一阶段为长休息，期间的休息为短休息。  
A02 预设时长：默认专注 25 分钟、短休息 5 分钟、长休息 30 分钟；改为其他预设后，下一场待开始的阶段使用新时长。  
A03 暂停继续：进行中暂停，剩余时间冻结；继续后从剩余时间倒计时，不重新满计。  
A04 跳过休息：短休息或长休息中执行跳过，阶段变为下一场专注。  
A05 重置周期：从周期中部重置后，回到第 1 次专注、状态为待开始，且不自动开始。  
A06 自动开始关闭：一场专注到时后进入短休息但保持待开始。  
A07 自动开始打开：专注到时自动进入并开始短休息；休息到时自动进入并开始下一场专注。  
A08 净时长与含中断时长：一场专注中插入已知长度的暂停，完成后 durationNet 不包含这段暂停，durationGross 约等于完成时间减开始时间。  
A09 网址包含匹配：规则 `x.com` 匹配 `https://x.com/`、`https://www.x.com/home`，不匹配明显无关的地址（如 `https://example.org/`）。  
A10 精确规则：规则 `*https://www.facebook.com` 匹配该精确地址，不匹配 `https://business.facebook.com`。  
A11 阻止模式：仅名单命中的 http 或 https 地址应拦截。  
A12 允许模式：名单未命中的 http 或 https 地址应拦截，命中的不拦截。  
A13 阶段门闩：状态为暂停、待开始、短休息、长休息时，匹配函数应报告「当前不启用屏蔽」。  
A14 拦截页 URL 排除：本地拦截页地址在任何模式下都不得再次被判定为需要替换。  
A15 导入样例：导入 `/workspace/flow/samples/flow-export-sample.csv` 后恰好得到 3 条会话，ID 分别为 `FC38D251-B896-4406-B06F-1C16F5A8649C`、`23B4F7C2-CE2C-4A0D-9D83-6709F7B81E53`、`DFE7E03C-3B98-461D-BBAC-95695E0CF79D`。  
A16 导入字段：第一条净时长 00:05:49、含中断 00:05:50、标签「学习」、标题为空、开始 2026-11-25 23:46:24、完成 2026-11-25 23:52:14；第三条标签为空。  
A17 导入幂等：对同一文件连续导入两次，会话总数仍为 3，无重复 ID。  
A18 导出格式：将这 3 条再导出，表头完全一致，时长为 `HH:MM:SS`，时间为 `YYYY-MM-DD HH:MM:SS`，Type、Title、Tag、ID 带引号。  
A19 导出往返：导出后再导入到空数据库，3 条字段一致。  
A20 日历默认标题：无标题有标签「学习」时，默认标题为「专注 · 学习」；无标题无标签时为「专注」。（若银耳确认了其他格式，以确认后的规则改写本项。）
